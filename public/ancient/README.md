# Ancient character forms

Oracle-bone (甲骨文), bronze (金文), and seal (篆書) glyphs from Wikimedia
Commons' public-domain "Ancient Chinese characters" project (古漢字):
https://commons.wikimedia.org/wiki/Commons:Ancient_Chinese_characters_project

All files here are public domain (PD ancient script). Regenerate with
`npm run build-ancient-forms`. `manifest.json` lists which forms each
character has; the app only shows an evolution when forms exist.
